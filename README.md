# Peel&Explain Website

Production-ready static website for the Peel&Explain media brand.

## Included
- Responsive homepage
- Topic and featured video sections
- About and FAQ sections
- Mobile navigation
- Accessibility improvements
- SEO metadata and JSON-LD
- Open Graph social artwork
- robots.txt and sitemap.xml
- Web app manifest and favicon
- Branded 404 page
- Vercel configuration and security headers
- Central social-link configuration

## Before public launch
Edit `config.js` and replace the placeholder YouTube and Facebook URLs with the official Peel&Explain pages.

The project currently uses `https://peelandexplain.com/` as the intended canonical domain. If another domain is selected, update `index.html`, `robots.txt`, and `sitemap.xml`.

## Deployment
This is a static site and is ready for Vercel. No build command is required.
